# PC-901 Toast Notification System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Sonner-based toast surface (`lib/notify.ts`) and migrate the lone `alert()`, two silent `console.warn` sites, and four non-fatal `ErrorModal` template-error uses to it. Foundation for PC-911.

**Architecture:** Install `sonner`. Mount `<Toaster />` once in the root layout. Add a thin wrapper module `frontend/lib/notify.ts` exposing `notify.{success,error,warning,info}` so call sites depend on our API surface, not Sonner directly. Migrate seven call sites in `frontend/app/page.tsx` mechanically. The bespoke `TemplateNotification` (template save/load celebrations), `ErrorModal` (Excel error + fatal run errors), and `SuccessCelebration` (post-run hero) intentionally stay as-is.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Vitest + Testing Library, `sonner` ^1.x.

**Reference:** [`docs/superpowers/specs/2026-05-10-pc-901-toast-notifications-design.md`](../specs/2026-05-10-pc-901-toast-notifications-design.md)

- [ ] **Step 3: Write the minimal implementation**

Create `frontend/lib/notify.ts`:

```ts
import { toast } from 'sonner';

// PC-901: thin wrapper over sonner so future swaps / centralised tweaks
// happen in one place. Bespoke template success notifications go through
// TemplateNotification, NOT this module — that distinction is intentional.
export const notify = {
  success: (message: string, opts?: { description?: string }) =>
    toast.success(message, opts),
  error: (
    message: string,
    opts?: {
      description?: string;
      action?: { label: string; onClick: () => void };
    },
  ) => toast.error(message, opts),
  warning: (message: string, opts?: { description?: string }) =>
    toast.warning(message, opts),
  info: (message: string, opts?: { description?: string }) =>
    toast.info(message, opts),
};
```
